# The game's own sounds, as script/soundgen makes them: each from the
# description on its line (ElevenLabs' text-to-sound-effects), written to
# resource/sound/made/<name>.ogg. Game/View/Audio says which is heard when.
#
#   name | seconds | once or loop | what it should sound like
#   name | seconds | music        | what the piece should be like
#   name | seconds | join         | FIRST then SECOND [after N]
#
# A line changed does not change the sound: script/soundgen --force NAME
# makes it again (and it will not be the same sound twice). A join is
# SECOND (any sound under resource/sound) begun at FIRST's loudest
# moment, or N seconds after it, with FIRST heard until then and fading
# out over the 'seconds' after.
#
# What was tried and not kept (the owner's ear, 2026-11-11): generated
# laser shots and warp-drive sounds, and generated sounds for docking and
# undocking, an order refused, a lock made and lost, a job begun and
# done, and a skill trained. The engine's old ones are better, and are
# what the game plays (weapon/pulse/1, jumpdrive, ui, productionlab).
