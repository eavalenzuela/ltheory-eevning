# The game's own sounds, as script/soundgen makes them: each from the
# description on its line (ElevenLabs' text-to-sound-effects), written to
# resource/sound/made/<name>.ogg. Game/View/Audio says which is heard when.
#
#   name | seconds | once or loop | what it should sound like
#
# A line changed does not change the sound: script/soundgen --force NAME
# makes it again (and it will not be the same sound twice).
