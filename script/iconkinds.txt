# The inventory's icons: one for each kind of item (the owner, 2026-11-23:
# "We should do this for all items, not just modules", "By category, of
# course"), drawn by script/artgen sheet in the manner they picked (cel).
# A line is: key | colour | what it stands for. A "== name" line starts a
# sheet (up to 16, drawn together so they match); a "!!" line under it is
# said to the model too. Each group has one colour family, so a kind reads
# at a glance. Skill books share one icon (the owner: "I don't even know if
# skill books need more than 1 icon").
# Blueprints are their item's icon with a mark the game draws; paints keep
# their swatches; size and tech level are marks the game draws over.
